# Cuadre

App sencilla para iPhone para registrar **ingresos y gastos**.

- Muestra la **Ganancia / Pérdida** (ingresos − gastos) y dos barras comparativas.
- Lista de **Movimientos** con opción de eliminar (doble confirmación).
- **Respaldo**: exportar / importar los movimientos en un archivo.
- Funciona sin internet una vez instalada.

**Privacidad:** no hay servidor ni base de datos. Todo lo que registra cada persona se guarda únicamente en la memoria de su propio iPhone. Este repositorio solo contiene la app vacía.

## Instalar en iPhone

1. Abrir **https://elvislg06.github.io/cuadre/** en **Safari**.
2. Tocar **Compartir → "Añadir a pantalla de inicio"**.

## Actualizar

Cambiar `VERSION` en `sw.js` en cada publicación para que los iPhones muestren el aviso "Nueva versión disponible".
